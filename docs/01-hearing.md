# 听觉：把"听见"拆成可验证的数字

## 一、六件套

一段音视频进来，能做六件事：

| 件 | 输出 | 典型用途 |
|---|---|---|
| 转写 | 时间戳 + 文本 | 字幕、引用 |
| 节奏 | BPM、拍网格、切点是否踩拍 | 卡点剪辑 |
| 旋律 | 音域、常用音、调性 | 判断段落有没有抬起来 |
| 和弦 | 和弦时间线 | 和声节奏、段落 |
| 结构 | 段落边界、鼓与人声进出 | 找呼吸点 |
| 分离 | 人声轨 / 伴奏轨 | 以上全依赖它 |

**六件里，分离是地基。** 伴奏/人声没分开时，音高跟踪器锁的是最响的基频——流行混音里通常是贝斯，不是人声。看到"人声音域 E2–G3"这种结果，先怀疑分离，不要怀疑歌手。

## 二、哪些数字不能信（实测）

1. **BPM 的"不确定"判断可能挂错数**。有些实现先算与次选的差距，再在"和声节奏复核"里改判 BPM；改判之后输出的是新 BPM、"不确定"标记还是旧的。**检查通过，结论仍可能错**。落地判据：`bpm == candidates[0].bpm` 且 `ambiguous == false` 且两套方法 agree，三条同时成立才可以写"拍是 N"。
2. **残差小不代表网格准**。只统计落在假设网格附近的峰，结构上残差就会小。**看 used/total，不看 ms。**
3. **和弦的"根音明确"可能只是配额**。有的实现按"本文件段级差距前 25%"发放，任何文件都会产出约四分之一"明确"。**这是相对名次，不是概率。** 引用只写 root，不写品质，不写"说明是某调"。
4. **结构切点通常没有置信度字段**。最不可验的数字被当成和别的一样可靠——**能标记的字段会误导人以为整份报告都标了**。写句子时降级："分析器在 1:47 切了一刀"，不写"第二段从 1:47 开始"。
5. **置信度不是准确率**。语言识别的 1.00 是"在给出的语种里赢得彻底"，它的选项里**没有"都不是"**。域外素材（老唱片、戏曲、强噪声）照样给 1.00。
6. **覆盖率不是准确率**。它只说明"识别器愿意认领多少时间轴"，不说明认领的部分对不对。

## 三、引用规则（可以直接照抄）

- 数字写**区间**（116–141），不写单值。带区间的数字在转述里不会退化，带形容词的会。
- **元数据跟着句子走**：覆盖率、前端版本、幻觉丢弃数、hit 率，不许只留在报告里。
- **按前端分组数证据**：共享同一条分离前端的转写、和弦、结构，只能算一条。它们一致只证明前端错得一致。
- **顺序可查**：先写下自己的听感，再跑工具。工具调用时间戳早于第一句描述，说明判断已经外包。
- **任何字段不进因果句**："因为 113 BPM 所以是舞曲""大七所以忧郁"都是把测量当解释。

## 四、一句判错法

> 这句话要错，得是哪件事错了？那件事有没有人真查过？

答案若落在工具**从没声称测量过**的东西上（"唱词说了什么""好不好听"），这次引用就是错的。

## 五、域外

声学时代录音、无稳定节拍的独奏、非西方唱腔、强噪声——这些不是"难"，是**域外**。域外素材默认不可引用，只能当环境声。判断看素材（年代、有没有稳定鼓、语言在不在模型见过的那批），不看字段。
