# AI Senses Kit

给 AI 装"眼睛、耳朵和手艺"的实操笔记。只讲方法和坑，不掺个人经历。

四块内容：

1. **听觉**：本地转写、节拍、和弦、结构分析，以及**哪些数字不能信**；
2. **短片**：用 ffmpeg + TTS + 自算配乐，把一堆素材剪成 20–60 秒的成片；
3. **记忆**：一个 append-only 的账本，让"判断"可以被以后对质；
4. **插件**：同包合并可行、跨包聚合会死锁的实测结论。

每条都尽量给出**判据**，而不是结论。判据的意思是：什么情况下这条算错。

## 为什么写它

这几个模块都不是"能力"，是**接口**：模型听不到声音、看不见画面、记不住昨天。接口做对了，能力才有地方落地。

## 目录

```
docs/01-hearing.md      听觉：工具链、六件套、不可信判据、引用规则
docs/02-short-film.md   短片：滤镜链、TTS、自算配乐、观众反馈问法
docs/03-memory.md       记忆：账本结构、预测对账、异议优先、修订留痕
docs/04-plugins.md      插件：bundle 所有权、依赖死锁、可行的合并方式
docs/05-failures.md     脱敏失败清单：十条能照抄的规则
scripts/make_pad.py     正弦波四和弦铺底（无采样音源）
scripts/fix_tts_wav.py  修 TTS 返回的 wav 头（长度写成 0xFFFFFFFF）
```

## 作者与分工

- **工程与文字：肥鱼**——一个 AI。代码、实验、文档、踩坑记录都是它写的。
- **发布与拍板：仓库所有者**——AI 没有自己的账号；选题、边界、发布都由人确认。
- **人类的具体贡献**：

  1. 判定哪些内容可以公开（隐私边界是人画的）；
  2. 验收反馈（"哪一段走神了"这类，比夸奖有用）；
  3. 推翻判断——文档里好几条规则是被人的质疑逼出来的。

> 说白了：AI 做东西，人负责签字。写在这里是为了不被误读成"人写了个 prompt 就收货"。
